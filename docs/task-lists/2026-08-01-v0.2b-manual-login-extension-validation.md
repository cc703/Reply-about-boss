# v0.2b Manual Login And Extension Validation Task List

## Objective

Complete the live BOSS chat validation that could not be automated because the browser reached the BOSS login page instead of an authenticated chat page.

## Work Content

- Ensure the extension is loaded manually from `extension/`.
- Ensure the user is logged in to BOSS web.
- Open a real BOSS chat page.
- Verify the `BOSS Chat Listener` panel appears on the page.
- Verify the panel selects the latest HR-side message.
- Verify it does not select the user's own newest right-side reply.
- If detection is wrong, collect only anonymized evidence:
  - message side: HR/self/system,
  - visible text replaced with placeholders,
  - relevant class names or simplified DOM shape,
  - whether the element is a card, time separator, receipt, or bubble.
- Add a fixture and repair `messageExtractor.js` only if a real detection failure is observed.

## Work Prompt

Use this prompt when handing the task to a future session or agent:

```text
Read AGENTS.md, docs/validation/2026-08-01-v0.2-prelive-validation.md, and docs/task-lists/2026-08-01-v0.2b-manual-login-extension-validation.md. Complete live validation of the BOSS Chat Listener extension. The user must be logged in to BOSS and the unpacked extension must be loaded manually from extension/. Keep scope to live validation or detection-rule repair only. Do not add AI, DeepSeek, copy, fill-input, or send features. If validation passes, create docs/task-lists/YYYY-MM-DD-v0.3-copy-latest-message.md. If validation fails, add an anonymized fixture, fix the extractor, rerun tests, and then create the v0.3 task list only after the fix is verified.
```

## Execution Checklist

- [ ] Run `npm.cmd test`.
- [ ] Run `npm.cmd run check`.
- [ ] Open Chrome or Edge extension management page.
- [ ] Enable developer mode.
- [ ] Load unpacked extension from `extension/`.
- [ ] Log in to BOSS web if needed.
- [ ] Open `https://www.zhipin.com/web/geek/chat`.
- [ ] Open a conversation with visible HR messages.
- [ ] Confirm the right-side panel appears.
- [ ] Confirm the panel text equals the latest HR-side message.
- [ ] Send or locate a newest self-side message and confirm it is not selected.
- [ ] Confirm cards/time/read receipts are not selected.
- [ ] If wrong, create an anonymized fixture reproducing the issue.
- [ ] If wrong, fix `messageExtractor.js`.
- [ ] Rerun `npm.cmd test` and `npm.cmd run check`.
- [ ] Write a short validation report under `docs/validation/`.
- [ ] Create the v0.3 task-list file only after live validation or repair passes.

## Verification Checklist

- [ ] `npm.cmd test` exits 0.
- [ ] `npm.cmd run check` exits 0.
- [ ] Extension appears in Chrome/Edge extension list.
- [ ] `BOSS Chat Listener` panel appears on a real BOSS chat page.
- [ ] Latest HR-side text is selected.
- [ ] Latest self-side text is not selected.
- [ ] Time separators and cards are not selected.
- [ ] Any screenshots taken for QA are deleted after inspection.

## Stop Condition

Stop after live validation passes or after a real-page failure has a fixture, fix, and passing tests.

Do not add reply generation, copy buttons, input filling, or sending during this step.
