# v0.2c Reload Extension Live Recheck Task List

## Objective

Reload the fixed unpacked extension in Chrome/Edge and verify on the real BOSS chat page that the panel selects the latest HR-side message instead of the resume action label.

## Work Content

- Reload the unpacked `BOSS Chat Listener` extension.
- Refresh the active BOSS chat page.
- Recheck the conversation pattern that previously selected a resume action label.
- Recheck broad page-container class false positives after the latest hardening.
- Confirm the panel now selects the HR-side message bubble.
- Confirm the panel still ignores cards, time separators, and self-side messages.
- If the panel is still wrong, collect anonymized DOM/class evidence and repair the extractor again.
- Do not add copy buttons, DeepSeek, reply generation, input fill, or auto-send behavior.
