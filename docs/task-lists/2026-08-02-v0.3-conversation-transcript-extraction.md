# v0.3 Conversation Transcript Extraction Task List

## Objective

Replace the single latest-message detection surface with a local transcript extractor that identifies all visible current-conversation records and classifies them as HR, self, system, control, or unknown.

This step prepares clean context for a later DeepSeek reply-draft feature, but it must not call DeepSeek or generate replies.

## Work Content

- Read `AGENTS.md` and `docs/superpowers/specs/2026-08-02-conversation-transcript-reply-design.md`.
- Add a pure `conversationExtractor.js` module.
- Extract ordered visible transcript records from a BOSS-like chat DOM.
- Classify each record as `hr`, `self`, `system`, `control`, or `unknown`.
- Treat action controls such as `发简历` as `control`, not as chat messages.
- Keep `messageExtractor.js` compatible by selecting the latest high-confidence `hr` message from the transcript, or leave it as a wrapper around the new extractor.
- Update the panel to display recent cleaned conversation records.
- Keep all behavior local, with no API calls, no storage, no input fill, and no auto-send.
- Add anonymized fixtures and unit tests for transcript extraction.
- Add a validation report after implementation.
