# v0.3c Live Chat Container Recheck Task List

## Objective

Reload the fixed unpacked extension and verify on the real BOSS chat page that the panel no longer displays third-party assistant/page chrome text as conversation records.

## Work Content

- Reload the unpacked `BOSS Chat Listener` extension from the local `extension/` directory.
- Refresh the active BOSS chat page.
- Confirm the panel subtitle is `识别当前会话记录`.
- Confirm the panel records show only HR, 我, and 系统 rows.
- Confirm no `未知` rows are displayed.
- Confirm third-party assistant text such as `智能对话`, `海投助手`, `Yangshengzhou`, or standalone page chrome does not appear in record rows.
- Confirm `发简历` and PK cards do not appear as conversation records.
- If the live page is still wrong, collect anonymized text/class evidence and add another fixture before changing code.
