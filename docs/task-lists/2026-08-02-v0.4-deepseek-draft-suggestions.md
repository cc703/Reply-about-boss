# v0.4 DeepSeek Draft Suggestions Task List

## Objective

Add user-reviewed reply draft suggestions based on the cleaned v0.3 conversation transcript, while preserving the rule that the extension never auto-fills or auto-sends messages.

## Work Content

- Confirm v0.3 transcript extraction is stable on a real BOSS chat page.
- Write a v0.4 design spec before implementation because this step introduces an external API and private chat context handling.
- Add a local backend service, preferably FastAPI, to call DeepSeek.
- Keep `DEEPSEEK_API_KEY` in local environment only.
- Send only cleaned transcript context from the extension to the local backend after the user explicitly requests a draft.
- Return 1-3 reply suggestions with tone labels such as `稳妥`, `积极`, and `留有余地`.
- Show suggestions in the panel for manual review.
- Do not fill the BOSS input box.
- Do not click send.
- Do not persist raw chat records.
- Add privacy and failure-state UI.
