# v0.5 Manual Copy Draft Task List

## Objective

Add a manual copy action for generated reply drafts without filling the BOSS input box or sending messages.

## Work Content

- Verify v0.4 draft generation works with a real local `DEEPSEEK_API_KEY`.
- Add a copy button for each generated draft.
- Copy only the selected draft text to the system clipboard after a user click.
- Show copied/success/error feedback in the panel.
- Do not locate or modify the BOSS input box.
- Do not auto-send or click any BOSS page button.
- Keep draft suggestions and copy actions human-controlled.

Use this prompt when handing the task to a future session or agent:

```text
Read AGENTS.md, docs/validation/2026-08-02-v0.4-deepseek-draft-suggestions-validation.md, and docs/task-lists/2026-08-02-v0.5-manual-copy-draft.md. Add tests for copy-state rendering and verify forbidden behavior scans. Run npm.cmd test, npm.cmd run check, backend tests if touched, Chrome fixture smoke, and privacy scans before claiming completion.
```
