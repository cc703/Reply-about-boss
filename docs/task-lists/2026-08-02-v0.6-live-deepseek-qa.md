# v0.6 Live DeepSeek QA Task List

## Objective

Verify the complete manual workflow on the real BOSS page with a real local DeepSeek API key:

```text
识别会话 -> 生成回复草稿 -> 手动复制 -> 用户自行粘贴发送
```

## Work Content

- Start the backend with a real local `DEEPSEEK_API_KEY`.
- Reload the unpacked extension.
- Refresh a real BOSS chat page.
- Confirm clean conversation records.
- Click `生成回复草稿`.
- Confirm the backend returns useful drafts.
- Click `复制` on one draft.
- Confirm the selected draft is copied to clipboard.
- Confirm the extension does not fill BOSS input or send anything.
- Document any model quality issues and prompt improvements.

## Work Prompt

Use this prompt when handing the task to a future session or agent:

```text
Read AGENTS.md, docs/validation/2026-08-02-v0.4-deepseek-draft-suggestions-validation.md, docs/validation/2026-08-02-v0.5-manual-copy-draft-validation.md, and docs/task-lists/2026-08-02-v0.6-live-deepseek-qa.md. Start the local FastAPI backend with a real local DEEPSEEK_API_KEY without printing the key. Reload the unpacked extension, refresh a real BOSS chat page, generate reply drafts, copy one draft, and verify the extension never fills the BOSS input or sends a message. If model output is poor, adjust only backend prompt policy with tests. Do not add auto-send, input fill, cookie/session handling, scraping, or platform bypass behavior.
```
