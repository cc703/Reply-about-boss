# v0.10b Live Tone Selector QA Task List

## Objective

Verify extension version `0.10.0` in the user's existing logged-in BOSS browser profile, focusing on tone controls, custom input, rendered draft quality, copying, and privacy boundaries.

## Work Content

- Reload the unpacked extension from `extension/` and refresh the BOSS chat tab.
- Confirm the five tone choices render without clipping or overlap.
- Confirm the custom input appears only for `自定义` and remains temporary.
- Generate drafts with at least two presets and one custom tone.
- Verify generated wording follows the selected style while staying grounded in the visible conversation.
- Verify copying is manual and the BOSS input remains unchanged.

Verify no invented ability, interest, schedule, attendance, or availability; no raw JSON; manual copy only; no BOSS input modification; and no API Key in DOM, extension storage, logs, or response bodies.
