# v0.11b Live Drag QA Task List

## Objective

Verify draggable panel behavior for extension version `0.11.0` on the real BOSS page without changing or sending any chat message.

## Work Content

- Reload the unpacked extension and refresh the BOSS chat page.
- Drag the panel from its title bar in every direction.
- Confirm the panel remains recoverable at all viewport edges.
- Confirm dragging does not interfere with collapse, scrolling, tone selection, generation, or copying.
- Confirm page refresh resets the position because coordinates are intentionally not persisted.

## Work Prompt

```text
Read AGENTS.md, docs/validation/2026-08-16-v0.11-draggable-panel-validation.md, and docs/task-lists/2026-08-16-v0.11b-live-drag-qa.md. Reload extension/ as version 0.11.0 in the existing logged-in browser profile and refresh the BOSS chat page. Drag only from the panel title bar. Check all viewport edges, rapid movement, release outside the original header area, collapse-button clicks, transcript scrolling, tone selection, draft generation, and manual copy. Confirm the panel never becomes inaccessible, no text is selected while dragging, page controls are unaffected, the BOSS input remains unchanged, and no message is sent. Refresh the page and confirm the position resets. Record only anonymized results. Add a failing regression test before any source fix.
```

- [ ] Automated tests still pass after any fix.
