# v0.7 Live Popup API Key QA Task List

## Objective

Verify that a real Chrome extension popup can save a user-provided DeepSeek API Key to Windows Credential Manager, retain it across browser restarts, and generate reply drafts without exposing the Key to the BOSS page or extension storage.

## Work Content

- Start the local backend with the latest code.
- Reload the unpacked `extension/` directory in Chrome.
- Open the extension toolbar popup.
- Save a real user Key without copying it into chat or sharing it with an agent.
- Close and reopen the browser, then verify only configured status is shown.
- Open a real BOSS chat page and generate drafts manually.
- Clear the Key from the popup and verify the configured status changes.
- Inspect the BOSS page DOM and backend responses for accidental Key exposure.

Start the local backend without printing any secret, reload the unpacked Chrome extension, use the toolbar popup to save a real DeepSeek API Key, close and reopen Chrome, verify only configured status is shown, then generate reply drafts on a real BOSS chat page. ## Stop Condition

Stop immediately and report a scoped failure if the Key appears outside the popup request or Windows Credential Manager, or if a fix would require auto-fill, auto-send, cookie handling, or platform bypass.
