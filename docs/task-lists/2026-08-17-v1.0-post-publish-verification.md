# v1.0 Post-Publish Verification Task List

## Objective

Verify that the public GitHub repository matches the approved local source package and contains no private artifacts after the initial push.

## Work Content

- Confirm the default branch and latest commit on GitHub.
- Compare the remote file tree with the local committed tree.
- Re-run a remote-facing secret and privacy scan on tracked files.
- Confirm `LICENSE`, README, `.gitignore`, extension source, backend source, tests, and docs are present.
- Confirm `.env`, virtual environments, OMX state, logs, screenshots, resumes, documents, browser profiles, and API Keys are absent.
- Confirm repository visibility and description are intentional.

## Work Prompt

```text
Read AGENTS.md, docs/validation/2026-08-17-v1.0-release-preparation.md, and this task list. Verify the published GitHub repository https://github.com/cc703/Reply-about-boss against the local committed tree. Do not push new changes during verification. Inspect the remote default branch, commit, files, license, README, ignore rules, and privacy boundaries. Run a tracked-file-only secret scan locally and inspect the GitHub file list for private artifacts. Record only anonymized evidence. If a private file or credential is found, stop and report it before attempting any remediation.
```

- `verifier`: compare local and remote state.
- `code-reviewer`: perform public-source privacy review.
- `git-master`: diagnose branch or remote discrepancies.

## Expected File Changes

- Create: `docs/validation/YYYY-MM-DD-v1.0-post-publish-verification.md`
- Do not modify source or push during verification.

## Execution Checklist

- [ ] Inspect `git status --short` and `git log --oneline`.
- [ ] Inspect `git ls-tree -r origin/main`.
- [ ] Compare local HEAD to `origin/main`.
- [ ] Scan tracked files for credentials and personal data.
- [ ] Inspect public GitHub repository file list and license.
- [ ] Confirm ignored private paths are absent remotely.

## Verification Checklist

- [ ] Local `HEAD` equals `origin/main`.
- [ ] Remote tree contains only approved public files.
- [ ] No credential or personal-data scan hits exist.
- [ ] Repository is public only if intentionally selected.
- [ ] README and MIT LICENSE render correctly on GitHub.

## Stop Condition

Stop when local and remote commit/tree state match and no privacy issue is found. If any private artifact is present, stop before modifying remote history.
