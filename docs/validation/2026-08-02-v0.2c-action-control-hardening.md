# v0.2c Action Control Hardening

## Scope

Harden the listener after the live-page `发简历` false positive so generic page controls are less likely to be selected as chat messages.

## Root Cause

The earlier detector treated broad class names such as `chat`, `dialog`, `content`, and `boss` as positive message or HR signals. On BOSS pages these words can appear on page containers or action controls, not only message bubbles. That made action text too easy to accept as an uncertain chat candidate.

## Changes

- Removed broad `boss` from HR-side class scoring.
- Removed broad `chat`, `dialog`, `text`, and `content` from message-class scoring.
- Kept narrower message signals such as `message`, `msg`, `chat-message`, `chat-bubble`, `chat-item`, and `bubble`.
- Added action/control class penalties for names such as `action`, `operation`, `operate`, `toolbar`, `footer`, `button`, `btn`, `menu`, and `resume`.
- Added tests proving generic action controls are rejected and broad page container classes do not create false confidence.
