# v0.3 Conversation Transcript Validation

## Summary

v0.3 changes the extension from latest-HR-message display to current visible conversation transcript display.

Verified locally on 2026-08-02:

- Transcript extraction classifies HR, self, system, control, and unknown records.
- Resume actions such as `发简历` are classified as controls and excluded from panel conversation records.
- The legacy latest-HR API can derive the latest HR message from transcript output.
- The panel renders multiple cleaned records from an anonymized fixture.
- No network, storage, extension messaging, input fill, or send behavior was added.
