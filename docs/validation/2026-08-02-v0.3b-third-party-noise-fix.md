# v0.3b Third-Party Noise Fix Validation

## Problem

The live BOSS page screenshot showed the panel listing non-chat text as `未知`, including:

- `沟通`
- `BOSS`
- `智能对话 · 高效沟通`
- `[13:47:54] 欢迎使用海投助手，我将自动发送简历!`
- `© 2026 Yangshengzhou · All Rights Reserved.`

## Root Cause

The extractor still scanned the whole document and `conversationRecords` included `unknown` records. That allowed page chrome, third-party floating panels, and unrelated assistant UI to appear in the user-facing conversation list.

## Fix

- Keep `records` as full diagnostic output.
- Restrict user-facing `conversationRecords` to `hr`, `self`, and `system`.
- Add a defensive panel filter so `unknown` and `control` records are not rendered.
- Add conservative chat-container selection before DOM candidate collection.
- Hide noisy internal `candidate/unknown` counts from the panel and show `会话 / 忽略控件` instead.
- Add fixture noise matching the observed third-party assistant panel.
