# v0.4 DeepSeek Draft Suggestions Validation

## Summary

v0.4 adds manual reply draft suggestions through a local FastAPI backend.

Validated behavior:

- The extension still extracts clean conversation records.
- The panel now shows a manual `生成回复草稿` button.
- The extension sends only cleaned `hr/self` records to localhost.
- The backend owns the DeepSeek call.
- Missing `DEEPSEEK_API_KEY` returns a controlled error.
- No auto-fill or auto-send behavior was introduced.

## Privacy And Forbidden Behavior

Validated by code review and tests:

- Extension request payload contains only cleaned `role/text` records.
- Extension rejects non-localhost endpoints.
- Extension does not directly call DeepSeek.
- Backend does not persist requests or responses.
- No input fill, auto-send, cookie, login automation, protocol interception, or scraping behavior was introduced.
