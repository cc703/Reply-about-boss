# v0.11 Draggable Panel Validation

## Scope

Version `0.11.0` makes the injected BOSS Chat Listener panel movable from its title bar. The change is limited to panel positioning and does not alter transcript extraction, DeepSeek requests, API Key handling, copying, input filling, or sending behavior.

## Implemented Behavior

- Title-bar dragging through Pointer Events for mouse, pen, and touch input.
- Pointer capture keeps movement active when the pointer leaves the header.
- An 8-pixel viewport boundary prevents the panel from being lost off-screen.
- Previously dragged panels are re-clamped when the viewport resizes.
- Collapse and other interactive controls do not start dragging.
- Header cursor changes from `grab` to `grabbing` during movement.
- Position remains in the current page instance only and is not stored.
- No extension permission was added.
