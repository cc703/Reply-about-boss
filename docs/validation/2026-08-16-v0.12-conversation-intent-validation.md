# v0.12 Conversation Intent Validation

## Scope

Version `0.12.0` adds a reply-purpose layer for common job-seeking conversation stages. The default `自动判断` mode distinguishes normal follow-up, recruiter rejection, and natural conversation endings. The user can override it with `继续了解`, `婉拒岗位`, or `礼貌结束` before manually generating a draft.

## Implemented Behavior

- Automatic recruiter-rejection recognition resolves to `acknowledge_rejection`.
- Automatic waiting/result/closing recognition resolves to `close`.
- Other recruiter messages resolve to `continue`.
- Manual purpose selection overrides automatic recognition.
- The selected purpose is sent only to the localhost backend with cleaned `hr/self` transcript records.
- DeepSeek receives explicit purpose guidance in the prompt.
- A deterministic backend guard rejects terminal drafts that ask new questions or restart the conversation.
- Manual decline drafts must explicitly state that the role is not being considered.
- Two invalid model attempts fall back to a local purpose-specific safe response.
- Existing tone controls remain independent from reply purpose.
- Drafts remain review-only: no BOSS input filling and no automatic sending were added.
