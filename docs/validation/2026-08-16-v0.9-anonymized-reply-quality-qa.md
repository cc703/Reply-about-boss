# v0.9 Anonymized Reply Quality QA

## Scope

This run validates five common recruiter intents through the local v0.9 backend using anonymized text. It also records the remaining real-browser limitation. No BOSS account data, API Key value, resume content, employer name, or contact information was written to the report.

## Environment

- Backend: `http://127.0.0.1:8765`
- Key status: configured boolean only
- Browser: Microsoft Edge was running, but the current Codex session exposed no Chrome or Windows UI control runtime and Edge had no attachable debugging port.
- Browser fallback was not attempted against a new profile because it would not represent the user's logged-in BOSS session or installed extension state.

## First QA Findings

The first five-scenario run exposed three defects:

- technical answers invented Python/FastAPI/Flask knowledge and project experience;
- interview answers committed to a time without candidate confirmation;
- nested JSON or Markdown JSON could be displayed as literal draft text.

Regression tests were added before production changes. A second run showed that safe filtering could leave recruiter-follow-up and job-detail scenarios without drafts, so a labeled local fallback was added for known intents.

## Final Scenario Results

| Scenario | Result | Source |
| --- | --- | --- |
| General recruiter greeting | Passed with one grounded request for job details | `local-safe-fallback` |
| Technical skill question | Passed with three neutral drafts that request concrete role requirements | `deepseek-v4-flash` |
| Recruiter follow-up / concern | Passed without a delayed-response excuse or concern denial | `local-safe-fallback` |
| Job details already provided | Passed without repeating duties or claiming interest/availability | `local-safe-fallback` |
| Interview scheduling | Passed with three drafts that require schedule confirmation | `deepseek-v4-flash` |

All five categories returned at least one usable, human-reviewed draft. No output claimed unprovided technical experience, project history, interest, concern status, or availability.
